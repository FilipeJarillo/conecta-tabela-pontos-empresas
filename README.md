# Tabela de pontuação — Conecta Enterprise (Portal Samsung Empresas)

Página publicada pelo GitHub Pages e embedada por iframe no portal Conecta Enterprise, para o perfil e-promoter.

- `index.html`: a tabela, num arquivo só, sem requisições externas.
- Gerada pelo `build.py` em `cerebro/02_Projetos/Conecta Enterprise (Samsung)/Tabela de pontuacao - embed/portal-empresas/`.
- Para atualizar: rodar o `build.py`, copiar o HTML para `index.html`, commit e push. O site atualiza em 1 a 2 minutos.
